Questions

FAQよくある質問

料金、翻訳できる回数、PDF の送り先、アプリが開けないときの対処をまとめています。

Price料金と回数

お金はかかりますか？

かかりません。アプリは無料で、翻訳には Google の Gemini API の無料枠を使います。Google AI Studio で支払い方法を登録していなければ、無料枠を使い切っても請求は発生せず、その日の翻訳ができなくなるだけです。

1 日に何ページまで翻訳できますか？

1 ページの翻訳で、Gemini API を 1 回使います。アプリは 1 日 500 回を上限の目安として数え、その日の回数が 450 回を超えそうになると、翻訳を始める前に確認の画面を出します。回数は Mac の時計で毎日 0 時に 0 に戻ります。

Google 側の実際の上限は Google の都合で変わることがあります。いまの上限は Google AI Studio で確かめられます。

Translation翻訳について

翻訳できない PDF はありますか？

紙をスキャンしただけの PDF のように、文字が画像になっていて選択できない PDF は翻訳できません。PDF を開いて、文字をドラッグで選択できるかどうかで見分けられます。

翻訳はそのまま信じて編んでも大丈夫ですか？

機械による翻訳なので、目数や段数、記号を取り違えることがあります。原文と訳が左右に並んでいるので、数字や略語は原文と照らし合わせてから編んでください。

翻訳が始まらない、または途中で止まります
  • インターネットに接続しているか確かめてください。
  • API キーを貼り付けるときに、前後に余分な文字が入っていないか確かめてください。鍵のボタンから入れ直せます。
  • その日の無料枠を使い切っている場合は、翌日まで翻訳できません。

Privacyプライバシーと著作権

PDF や API キーはどこに送られますか？
  • API キーは使っている Mac の中にだけ保存されます。
  • PDF は 1 ページずつ、翻訳のために Google の Gemini API に送られます。アプリの作者に送られるものはありません。
  • Google の規約では、無料枠で送った内容を Google がサービスの改善に使う場合があるとされています。人に見せたくない内容を含む PDF は翻訳しないでください。
翻訳した PDF を人に渡してもいいですか？

販売されている編み物パターンには、作者が個人で使うことを条件にしているものがよくあります。翻訳した PDF を人に渡したり公開したりする前に、パターンの利用条件を確かめてください。

Installインストールと動作環境

「壊れているため開けません」と表示されて開けません

macOS がインターネットから入手したアプリに付ける印が原因で、この表示が出ることがあります。このサイトか GitHub からダウンロードしたアプリであれば、ターミナルで次のコマンドを実行すると印が外れ、開けるようになります。

xattr -dr com.apple.quarantine /Applications/KnittingTranslator.app

アプリケーションフォルダ以外に置いている場合は、/Applications/KnittingTranslator.app の部分を置いた場所に書き換えてください。

Intel プロセッサの Mac で使えますか？

いま配布しているアプリは、Apple シリコン（M1 以降）を搭載した Mac 向けです。Intel プロセッサの Mac では動きません。

Windows や iPhone で使えますか？

使えません。Knitting Translator は Mac 専用のアプリです。
