How to use

Guide使い方

API キーの登録は最初の 1 回だけです。2 回目からは PDF を入れて「翻訳を開始」を押すだけで使えます。

01 / API keyAPI キーを作って登録します

API キーは、アプリが Google の翻訳の仕組み（Gemini API）を使うための合言葉にあたる文字列です。Google アカウントがあれば無料で作れて、クレジットカードの登録はいりません。5〜10 分ほどかかります。

  1. ブラウザで Google AI Studio の API キーのページを開き、Google アカウントでログインします。
  2. 「Create API key」（日本語の表示では「APIキーを作成」）を押します。プロジェクトを選ぶ画面が出たら、「Create API key in new project」を押します。
  3. AIzaSy から始まる長い文字列が表示されます。右にあるコピーのボタンを押してコピーします。
  4. KnittingTranslator を開くと API キーの入力画面が出ます。入力欄に貼り付けて（command + V）、「保存」を押します。

API キーは人に教えないでください。キーを知った人が使うと、その回数もあなたの 1 日の無料枠から引かれます。

API キーを入れ替えたいときは、「翻訳を開始」ボタンと同じ列の右端にある鍵のボタンを押します。

02 / TranslatePDF を翻訳します

スクリーンショット：アプリのメイン画面（準備中）
  1. 翻訳したい PDF を画面上部の枠にドラッグして入れます。枠の中の「ファイルを選択」から選んでもかまいません。
  2. 「翻訳設定」で、パターンに合わせて「棒針」か「かぎ針」を選びます。選んだほうの用語集を使って訳します。
  3. 「翻訳を開始」を押します。

翻訳は 1 ページずつ進み、1 ページあたり 10〜30 秒ほどかかります。進み具合はバーで表示され、0〜90% が翻訳、90〜100% が PDF の作成です。途中でやめたいときは「キャンセル」を押します。

その日の翻訳回数に、これから翻訳する PDF のページ数を足すと 450 回を超えるときは、始める前に確認の画面が出ます。回数の数え方はよくある質問にあります。

03 / Saveできあがった PDF を保存します

翻訳が終わると、画面の下に対訳 PDF のプレビューが出ます。中身を確かめて「PDFを保存...」を押し、保存先を選びます。
