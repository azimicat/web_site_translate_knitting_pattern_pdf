About

Knitting Translator は英語で書かれた棒針編みとかぎ針編みのパターン PDF を日本語に翻訳する Mac 用アプリです。原文のすぐ横に日本語訳が並ぶので、英語の略語と編み方を照らし合わせながら編み進められます。

無料でダウンロード 使い方を見る

macOS 14 Sonoma 以降

Features

Knitting Translator でできること

01 / Side by side

原文のとなりに日本語訳が並びます

A4 の PDF の左に英語の原文、右に日本語訳が並びます。元の PDF の太字や斜体も引き継ぎます。

PDF の仕様を見る

k2tog左上 2 目一度sc細編み

02 / Glossary

棒針とかぎ針で用語集を使い分けます

k2tog（左上 2 目一度）や sc（細編み）のような略語は、選んだモードの用語集をもとに、日本語の編み方の名前に置き換えます。

モードの選び方を見る

03 / Free

料金はかかりません

翻訳には Google の Gemini API の無料枠を使います。用意するのは無料で作れる API キーだけで、クレジットカードの登録はいりません。

API キーの作り方を見る
How to start

3 ステップで使い始められます

  1. 01

    アプリをインストール

    zip をダウンロードして展開し、アプリケーションフォルダに移します。
  2. 02

    API キーを登録

    Google AI Studio で無料の API キーを作り、アプリに貼り付けます。
  3. 03

    PDF を翻訳

    PDF をドロップしてモードを選び、「翻訳を開始」を押します。
